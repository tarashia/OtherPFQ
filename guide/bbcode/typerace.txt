[display=Display your type race rotation]This is a fairly simple type race rotator - it's meant to be smaller than Marlowe's and let you customize how many types are shown at a time. Partially inspired by Hakano Riku's code (format and cursor design).

At the start and end of the type race season, ??? types will be displayed until you update the date setting for that season (and your type listing). This is intentional as the team assignments don't truly rotate anymore.

To use, replace the 18 type tags based on the order shown on the type race page. Do not change the dateset. Windowsize controls how many types are shown at once. Cursorpos sets which position the current type and arrow is shown in.
